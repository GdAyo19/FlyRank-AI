# Scraper

A web scraper for [Books to Scrape](https://books.toscrape.com/), a sandbox site built for scraping practice.

## Target classification

- **Which site**: [books.toscrape.com](https://books.toscrape.com/)
- **Why**: The site explicitly states "Books to Scrape We love being scraped!" and is labeled as a **Sandbox** — a demo website built so people can practise scraping on it. This is the only kind of site this assignment touches.
- **How much**: The first 3 catalogue pages only (60 books total).
- **What data to collect**: Book title, price, rating, availability, and category.
- **Why appropriate**: This site is intentionally designed for scraping practice; prices and ratings are randomly assigned and have no real meaning.
